# 追番记录 × 剧集信息联动（含番外）实现计划 v2

## Context（背景）

剧集信息功能已上线（`episode` 表，`ep_no` 为字符串，兼容 SP/番外）。追番记录需与剧集信息联动：录入时点选"看了哪几集"，并展示"看到哪里了"。

v1 已实现"连续区间点选 + 番外走备注"，用户要求 **SP/OVA/OAD 等番外也要能记录**，因此升级为 v2。

已确认决策：
1. **记录粒度 = 逐集多选**：数字正片 + SP/OVA/OAD 番外都可勾选，支持不连续。
2. **番外数据来源**：改 Bangumi 同步，拉取本篇（type=0）+ 特别篇（type=1）。
3. **统计口径**：番外算 1 集（`ep_count` = 勾选集数，含番外）。

## 1. 数据库（需手动执行 ALTER TABLE）

```sql
ALTER TABLE watch_log ADD COLUMN ep_nos VARCHAR(500) DEFAULT NULL
  COMMENT '观看的集号明细，逗号分隔（含SP/OVA/OAD番外）' AFTER ep_count;
```

字段语义重新定义：
- `ep_nos`：本次观看的集号列表（逗号分隔，按 sort 顺序，如 `1,2,3,SP`）——核心明细字段。
- `ep_count`：本次观看总集数 = `ep_nos` 明细数量（番外算 1 集）。
- `ep_start` / `ep_end`：数字正片的 min/max（用于"看到第几集"进度），仅看番外时为 NULL（列已 `DEFAULT NULL`）。

> 现有统计 SQL（`sum(ep_count)`、`max(ep_end)`、`getDailyStats`）**无需改**，番外自动计入"集数"统计。旧数据 `ep_nos` 为 NULL，兼容回退。

## 3. 前端

### `api/bangumi.js`
`fetchSubjectEpisodes` 拉 `type=0` + `type=1` 合并返回（本篇 + 特别篇）。

### `components/anime/AnimeForm.vue`
`syncEpisodes` 后 `form.episode` 只算数字正片数量（`epNo` 匹配 `/^\d+$/`），番外不计入总集数。

### `components/watch/WatchLogForm.vue`（核心重构：逐集多选）
- 拉取 `episodes` 后按 `sort` 升序渲染**所有集**为可 toggle 的 chip（数字集 + 番外都可勾选）。
- `selectedEps` 维护勾选集合；提交组装 `epNos`（join 逗号）、`epStart/epEnd`（数字 min/max）、`epCount`（选中总数）。
- 编辑回填：从 `initialValues.epNos` split 还原；旧数据无 `epNos` 回退区间。
- 校验：至少勾选一集或手填起止集；手填数字输入保留兜底。

### `views/watch/WatchDashboard.vue`
"观看剧集"列显示 `epNos` 明细，无 `epNos` 回退 `E{epStart}-E{epEnd} ({epCount}集)`。

### `views/anime/AnimeDetail.vue`
- `getWatchProgress` 返回 `{ maxEpEnd, watchedEpNos }`。
- 剧集列表"状态"列：`epNo ∈ watchedEpNos` 标记"已看"（含番外）。
- 进度文案：`已看到第 X 集` + `共看 N 集（含番外）`。
