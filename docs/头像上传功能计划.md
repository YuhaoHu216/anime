# 头像上传功能计划

日期：2026-08-17

## 目标

在个人中心（Profile.vue）实现头像上传：用户选择本地图片后，可先进行放大/缩小/移动的取景裁剪预览，确认后再提交上传并保存到头像。

## 交互流程

```
点击头像 → 选择本地图片 → 弹出裁剪对话框(vue-cropper)
  → 放大/缩小/移动调整取景框(1:1 正方形) → 实时预览
  → 点击"确定" → 前端裁剪成 Blob 并上传
  → 后端保存文件并返回相对路径 → 调 updateProfile 写入 avatar_url
  → fetchUserInfo 全局刷新头像
```

- 裁剪对话框内实时预览即最终展示，满足"先预览、再提交"。
- 有"取消"按钮，不确认就不上传，不产生垃圾文件。

## 技术方案

采用"扩展通用 /file/upload"方案：animeId 改为可选，为 null 时按头像处理。

### 后端改动（3 处）

1. **application.yml**：`app.upload` 下新增 `avatar-dir: avatars`
2. **FileService / FileServiceImpl**：新增 `uploadAvatar(MultipartFile file, Integer userId)`，存 `avatars/` 目录，命名 `{userId}_{uuid8}.ext`，返回相对路径 `avatars/xxx.png`
3. **FileController.upload**：`animeId` 改 `@RequestParam(required = false)`；为 null 时走头像上传（`UserContext.getUserId()` 取当前用户，未登录抛异常）

封面上传调用处不受影响（前端始终传 animeId）。

### 前端改动（4 处）

1. **package.json**：新增 `vue-cropper` 依赖（npm install）
2. **src/api/file.js**：`uploadFile(file, animeId)` 的 animeId 改可选，为 null 时不 append 该字段
3. **src/views/Profile.vue**：头像 hover 显示"更换头像" → 选图 → 裁剪对话框（1:1 固定比例）→ 确定后上传+保存；现有头像展示改 `getFileUrl(userInfo.avatarUrl)`
4. **src/components/layout/AppHeader.vue**、**src/views/ShareProfile.vue**：头像展示改 `getFileUrl(...)`（必须修，否则相对路径头像显示不出）

## 错误处理

- 未登录上传 → 后端抛异常 → 前端全局拦截提示
- 非图片/超大 → `accept="image/*"` 限制 + 后端已有 10MB 上限
- 上传失败/保存失败 → 前端 ElMessage 提示，头像不变

## 不做的事（保持精简）

- ❌ 不自动删除旧头像文件（与现有封面逻辑一致）
- ❌ 不动其他无关文件
