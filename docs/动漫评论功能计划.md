# 动漫评论功能实现计划

日期：2026-08-26

## Context（背景）

当前动漫详情页只有展示信息，用户无法针对某部动画发表看法。本次为每部动画添加**评论功能**，支持文字+多图、用户名/头像展示、B站风格的子评论（可折叠）、点赞/点踩。

已确认的决策：
1. **时间格式**：24 小时制 `yyyy-MM-dd HH:mm`（前端格式化）。
2. **子评论层级**：只支持一层（所有回复挂在顶层评论下，回复子评论带 `@用户名`），类似 B站。
3. **点赞/点踩**：都做，可切换/取消，记录每个用户状态。
4. **评论不审核**：发布即显示（用户未提审核需求）。
5. **删除权限**：评论作者本人或管理员。
6. **图片上限**：每评论最多 9 张（单张 10MB 由现有 multipart 配置限制）。

## 1. 数据库

在 `src/main/resources/sql/anime.sql` 追加，生产同步执行两条 CREATE TABLE（新表无 ALTER 问题）：

```sql
CREATE TABLE comment (
  id INT AUTO_INCREMENT PRIMARY KEY,
  anime_id INT NOT NULL,
  user_id INT NOT NULL,
  parent_id INT DEFAULT NULL COMMENT '子评论的 parent_id 指向所属顶层评论（仅一层子评论）',
  reply_to_user_id INT DEFAULT NULL COMMENT '回复对象用户ID（子评论 @昵称 用）',
  content VARCHAR(2000) DEFAULT NULL COMMENT '文字内容（图片评论可留空）',
  images TEXT COMMENT '图片相对路径 JSON 数组，如 ["comments/1_ab12.png"]',
  like_count INT DEFAULT 0 COMMENT '点赞数',
  dislike_count INT DEFAULT 0 COMMENT '点踩数',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_anime_created (anime_id, created_at),
  INDEX idx_parent (parent_id),
  FOREIGN KEY (anime_id) REFERENCES anime(id) ON DELETE CASCADE,
  FOREIGN KEY (user_id) REFERENCES user(id),
  FOREIGN KEY (parent_id) REFERENCES comment(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='动漫评论表';

CREATE TABLE comment_like (
  id INT AUTO_INCREMENT PRIMARY KEY,
  comment_id INT NOT NULL,
  user_id INT NOT NULL,
  type TINYINT NOT NULL DEFAULT 1 COMMENT '1=赞 -1=踩',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_comment_user (comment_id, user_id),
  INDEX idx_user (user_id),
  FOREIGN KEY (comment_id) REFERENCES comment(id) ON DELETE CASCADE,
  FOREIGN KEY (user_id) REFERENCES user(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='评论点赞表';
```

要点：删顶层评论时子评论与点赞由 FK `ON DELETE CASCADE` 级联清理；图片以 JSON 数组字符串存 `images` 列，实体解析为 `List<String>`。

## 2. 后端（D:\Code\fullstack\anime\anime-backend）

### 2.1 图片上传扩展
- `application.yml`：`app.upload` 新增 `comment-dir: comments`。
- `FileService` / `FileServiceImpl`：新增 `uploadComment(MultipartFile file, Integer userId)`，复用私有 `saveFile(file, commentDir, userId + "_")`，返回相对路径 `comments/{userId}_{uuid8}.png`。
- `FileController`：新增 `POST /file/upload-comment`（multipart `file`），`UserContext.getUserId()` 取当前用户，未登录抛异常。该接口不在白名单内，自动走登录校验。

### 2.2 JwtInterceptor 可选鉴权改造（关键风险点）
现状：白名单在 `WebConfig.excludePathPatterns`，被排除路径直接 return true、**不填充 UserContext**，导致公开读评论接口带 token 也拿不到当前用户（无法返回点赞状态）。

改造：
- 白名单收敛进 `JwtInterceptor`（`PUBLIC_PATHS` 数组，用 `AntPathMatcher` 匹配），把 `/comment/list`、`/comment/children` 加入公开列表。
- `preHandle` 改为：**先尝试解析 token（有效则填充 UserContext），再按路径决定是否必须登录**。静态图片 GET 免登录逻辑保留。
- `WebConfig` 删除 `excludePathPatterns`，只保留 `addInterceptor(jwtInterceptor).addPathPatterns("/**")`。
- 回归重点：登录、注册、分享页、图片访问。

### 2.3 评论实体与 DTO
- `pojo/Comment.java`：DB 字段 `id, animeId, userId, parentId, replyToUserId, content, images, likeCount, dislikeCount, createdAt`；非库字段 `username, avatarUrl, replyToUsername, imageList(List<String>), replyCount, myType(0/1/-1), children(List<Comment>)`。
- `pojo/CommentLike.java`：`id, commentId, userId, type, createdAt`。
- `pojo/dto/CommentAddDTO.java`：`animeId, content, images(List<String>), parentId, replyToUserId`。

### 2.4 CommentMapper（注解 + XML，参照 WatchLogMapper）
`resources/mapper/CommentMapper.xml` 用 `<sql id="commentUserColumns">` 复用 join 用户（`user` 联查 `username/avatar_url`，`left join user rt` 取 `reply_to_username`）；`map-underscore-to-camel-case` 已开启，无需逐列 `@Results`。

方法清单：
- 写入：`insert`（useGeneratedKeys）、`incrLike/incrDislike/decrLike/decrDislike`、`insertLike/deleteLike/updateLikeType`、`deleteById`。
- 查询：`findById`、`findTopLevelByAnime`（`parent_id is null order by created_at desc`，供 PageHelper 分页）、`findChildrenByRootIds`（批量取一批顶层下全部子评论）、`countChildrenByRootIds`（GROUP BY parent_id 计数）、`findChildrenByRoot`（展开拉全部，升序）、`findLike(commentId,userId)`、`findLikesByCommentIds(ids,userId)`（批量当前用户点赞状态，避免 N+1）。

### 2.5 CommentService / Impl
- `list(animeId, page, pageSize, currentUserId)`：PageHelper 分页顶层评论 → 批量查子评论总数与全部子评论 → 每个根取**最近 3 条**子评论（升序展示）→ 批量回填 `myType`（一次 `findLikesByCommentIds`）→ 返回 `PageBean<Comment>`。
- `children(rootId, currentUserId)`：展开时一次拉全部子评论（升序）。
- `add(dto, userId)`：内容 trim 空且无图 → 抛异常；`parentId != null` 时校验父评论存在、其 `parentId == null`（强制单层）、`animeId` 一致；`images` 序列化 JSON 存入。
- `like(commentId, type, userId)`（`@Transactional`）：切换式——无记录插入 / 同类型取消 / 不同类型翻转，同步维护 `like_count/dislike_count`，返回最新 `{likeCount, dislikeCount, myType}`。
- `delete(id, userId)`：作者本人或管理员（`UserMapper.findById` 查 role）放行，否则抛"无权删除"；顶层评论由 FK 级联清理。

### 2.6 CommentController 接口清单
| 方法 | 路径 | 鉴权 | 请求 | 响应 data |
|---|---|---|---|---|
| GET | `/comment/list` | 公开（可选登录） | `animeId, page, pageSize` | `PageBean<Comment>`（含 children≤3、replyCount、myType、imageList、username、avatarUrl） |
| GET | `/comment/children` | 公开（可选登录） | `rootId` | `List<Comment>` 全部子评论 |
| POST | `/comment` | 登录 | body `CommentAddDTO` | `Result.success("评论成功", comment)` |
| POST | `/comment/like` | 登录 | body `{commentId, type}` | `{likeCount, dislikeCount, myType}` |
| DELETE | `/comment/{id}` | 登录 | 路径 id | `Result.success("删除成功")` |

Controller 统一 `UserContext.getUserId()`；公开接口未登录时传 `null`。

## 3. 前端（D:\Code\fullstack\anime\anime-frontend）

### 3.1 API 与工具
- `src/api/comment.js`：`getComments(params)` / `getCommentChildren(rootId)` / `addComment(data)` / `deleteComment(id)` / `likeComment(data)` / `uploadCommentImage(file)`（POST `/file/upload-comment`，multipart）。`src/api/index.js` 追加 `export * from './comment'`。
- `src/utils/date.js` 新增 `formatDateTime(str)`：ISO 时间 → `yyyy-MM-dd HH:mm`（24 小时制，手写 padStart，不引 dayjs）。

### 3.2 组件（新增 `src/components/anime/`）
**`CommentSection.vue`**（评论区容器，挂到 AnimeDetail）：
- Props：`animeId`。
- 评论输入框：未登录显示"去登录"（跳 `/login?redirect=当前页`）；登录显示 `el-avatar`(当前用户) + `el-input textarea`(maxlength 2000) + `el-upload picture-card`（`:auto-upload="false"`、`limit 9`）收集图片，提交时 `Promise.all` 逐个 `uploadCommentImage` 拿相对路径再 `addComment`。
- 列表：`CommentItem` 循环 + 复用 `Pagination` 组件；删除后刷新当前页；空态 `el-empty`"暂无评论"。
- 时间显示用 `formatDateTime(comment.createdAt)`。

**`CommentItem.vue`**（单条评论）：
- Props：`comment`、`animeId`；Emits：`deleted`。
- 头像 `el-avatar` + `getFileUrl(avatarUrl)` + `icon="UserFilled"` 兜底（与现有详情页一致）；图片 `el-image` + `preview-src-list` 点击放大。
- 折叠/展开：默认渲染 `comment.children`（后端给的最新 3 条）；点"共 N 条回复"展开 → `getCommentChildren(comment.id)` 拉全部并替换；收起复位为最近 3 条。
- 回复：点顶层"回复" → `replyTarget={parentId: comment.id, replyToUserId: null}`；点子评论"回复" → `{parentId: comment.id, replyToUserId: ch.userId}`，placeholder 带 `@昵称`；提交成功后本地刷新子评论、`comment.replyCount++`，不动顶层列表。
- 点赞/点踩：未登录警告；`likeComment({commentId, type})` 后用返回的计数与 `myType` 更新按钮状态（互斥高亮）。
- 删除：`comment.userId === userStore.userInfo?.id || userStore.isAdmin` 显示删除按钮，`ElMessageBox.confirm` 后 `deleteComment` → `emit('deleted')`。

### 3.3 AnimeDetail.vue 集成
在 `<div class="detail-layout">` 之后插入 `<CommentSection v-if="anime" :anime-id="anime.id" />`，`script` 中 import。评论区自管登录态，无需在父组件判断。
