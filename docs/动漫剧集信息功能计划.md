# 动漫剧集信息功能实现计划

## Context（背景）

当前动漫库（`anime` 表）只有 `episode`（总集数）一个数字字段，无法查看每集的名字、放送日期、时长。本次为动漫添加**逐集剧集信息**，类似 Bangumi 的展示效果。

已确认的决策：
1. **后端建 `episode` 表存储**；数据可通过前端"从 Bangumi 同步"按钮抓取，再手动编辑。
2. **放送时间** = 每集放送日期（如 `2026-04-05`）。
3. **时长**在数据库存**总秒数（int）**，展示时格式化为 `HH:MM:SS` / `MM:SS`。
4. **录入/编辑入口** = 嵌在 `AnimeForm.vue`（新增/编辑动漫共用表单）里的剧集编辑区。
5. **剧集不单独审核**，跟随动漫状态（动漫审核通过即生效）。

## 1. 数据库

在 `src/main/resources/sql/anime.sql` 追加 Step 8：

```sql
CREATE TABLE episode (
  id INT AUTO_INCREMENT PRIMARY KEY,
  anime_id INT NOT NULL COMMENT '所属动漫ID',
  ep_no VARCHAR(20) NOT NULL COMMENT '集号（1、2、SP、1.5 等）',
  name VARCHAR(200) DEFAULT NULL COMMENT '集名',
  air_date VARCHAR(20) DEFAULT NULL COMMENT '放送日期，如 2026-04-05',
  duration INT DEFAULT NULL COMMENT '时长（总秒数）',
  sort DECIMAL(10,2) NOT NULL DEFAULT 0 COMMENT '排序号（越小越靠前，来自 Bangumi sort）',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_anime_ep (anime_id, ep_no),
  KEY idx_anime (anime_id),
  CONSTRAINT fk_episode_anime FOREIGN KEY (anime_id) REFERENCES anime(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='剧集信息表';
```

要点：
- `air_date VARCHAR(20)` 与现有 `anime.broadcast_time VARCHAR(50)` 风格一致，前端 `el-date-picker value-format="YYYY-MM-DD"` 直接产出字符串。
- `ep_no VARCHAR(20)`（而非 INT）以兼容 SP/番外；`sort` 用于正确排序。
- `ON DELETE CASCADE`：删除动漫自动清理剧集。
- 无 Flyway，需在 dev 库手动执行该 `CREATE TABLE`。

## 2. 后端

### 新增文件
- `pojo/Episode.java`：`id, animeId, epNo, name, airDate, duration, sort(Double), createdAt, updatedAt`。
- `pojo/dto/EpisodeDTO.java`：`epNo, name, airDate, duration, sort` + `toEpisode()`。
- `mapper/EpisodeMapper.java`：`batchInsert` / `deleteByAnimeId`（@Delete）/ `findByAnimeId`（@Select，`order by sort asc, id asc`）。
- `resources/mapper/EpisodeMapper.xml`：仅 `batchInsert` 用 `<foreach>`。

### 修改文件
- `Anime.java`：加 `private List<Episode> episodes;`（非 DB 字段）。
- `AnimeAddDTO` / `AnimeUpdateDTO`：加 `private List<EpisodeDTO> episodes;`。
- `AnimeService` / `AnimeServiceImpl`：三个写方法签名加 `List<EpisodeDTO> episodes`；新增 `replaceEpisodes(animeId, episodes)`（先 `deleteByAnimeId` 再 `batchInsert`）；`findById` 回填 `episodes`。
- `AnimeController`：三个写接口调用传 `dto.getEpisodes()`。

**JWT 白名单无需改动**：读取复用 `/anime/info/{id}`，写入走已鉴权的 add/update/submit。

## 3. 前端

### 新增文件
- `src/utils/duration.js`：`parseDurationToSeconds` / `formatSecondsToDuration` / `parseDurationInput`。

### 修改文件
