# 标签字母排序与快速导航功能计划

## Context（背景与目标）

当前项目中标签功能存在以下不足：

1. **标签管理页**（`src/views/admin/TagManage.vue`）：标签平铺展示，顺序由后端 `order by id` 决定，无排序、无字母导航。标签几乎全是中文（热血、恋爱、科幻、奇幻…），无法按字母快速查找。
2. **添加/编辑动漫表单**（`src/components/anime/AnimeForm.vue`）：标签选择是 `el-select multiple filterable` 下拉，只能输入文字搜索，无字母快速导航，且**不能创建新标签**。

本次改造目标：

- 标签管理页：标签按 **A-Z 字母升序分组**展示，并支持**点击字母快速导航**定位。
- 添加/编辑动漫表单：标签选择改为**弹窗式选择器**，内含 A-Z 字母导航，并**支持创建新标签**。

已确认的设计决策：

- 中文标签按**拼音首字母**分组（引入 `pinyin-pro` 库），英文按首字母，数字/符号归入 `#`。
- 表单用**弹窗式选择器**。
- 创建标签用 **allow-create 风格**：输入不存在的名称按回车即创建并选中。

## 关键结论（探索所得）

- **后端无需改动**：`GET /admin/tags`（返回全部标签）与 `POST /admin/tags`（创建）已够用；`WebConfig` 仅做登录校验、无角色限制，登录用户均可创建标签。
- 前端项目实际位于 `D:\Code\fullstack\anime\anime-frontend`（非 CLAUDE.md 中的 my-agent-frontend）。
- 技术栈：Vue 3 `<script setup>` + Element Plus 2.14.2 + Pinia，包管理器 npm（存在 `package-lock.json`）。
- 全局标签缓存在 `src/stores/app.js`，由 `AppLayout.vue` 的 `onMounted` 中 `appStore.fetchTags()` 加载，表单可直接 `computed(() => appStore.tags)` 消费。
- 现有 `src/api/admin.js` 已有 `getTags / createTag / deleteTag`，直接复用。

## 改动明细（全部在前端，后端不动）

### 1. 安装依赖

在 `anime-frontend` 目录执行：

```
npm install pinyin-pro
```

### 2. 新建 `src/utils/tags.js` — 拼音首字母与分组工具

提供三个纯函数：

- `getInitial(name)`：返回标签分组字母（大写 A-Z 或 `#`）。
  - 英文/数字：取首字符（英文转大写）。
  - 中文字符：用 `pinyin(name, { pattern: 'first', toneType: 'none', type: 'array' })` 取首字拼音首字母转大写；非 A-Z 归 `#`。
  - 其它字符归 `#`。
- `sortTagsByName(tags)`：按拼音全拼 `localeCompare` 升序排序（用于组内排序）。
- `groupTagsByInitial(tags)`：返回 `[{ letter, tags }]`，字母按 A-Z 升序、`#` 排最后，组内按 `sortTagsByName` 排序。

### 3. 新建 `src/components/common/AlphabetNav.vue` — 字母索引条组件（复用）

- props：`letters`（可用字母数组，含 `#`）、`active`（当前字母）。
- emits：`select(letter)`。
- 渲染一列字母按钮，点击触发 `select`；不在 `letters` 中的字母置灰禁用。样式贴合项目暖色主题（参考现有 `.score-option` 风格）。
- 供「标签管理页」与「TagSelector 弹窗」两处复用。

### 4. 改造 `src/views/admin/TagManage.vue` — 标签管理页

- 用 `groupTagsByInitial(tags)` 生成分组数据，替换原平铺 `v-for`。
- 按分组渲染：每个字母一个 `section`，标题为字母，下方该组标签 chips（`el-tag closable` 保留删除）。
- 右侧竖排 `AlphabetNav`，点击字母调用 `scrollIntoView`（或 `document.getElementById('tag-letter-'+letter).scrollIntoView()`）定位到对应分组；滚动时高亮当前字母（可选）。
- 保留现有「创建/删除标签」逻辑，创建/删除成功后重新 `fetchTags` 并刷新全局缓存（原有逻辑不变）。

### 5. 新建 `src/components/anime/TagSelector.vue` — 弹窗式标签选择器

- 对外 `v-model` 绑定已选 `tagIds`（`number[]`），内部用 `defineModel` 或 `modelValue` + `emit('update:modelValue')`。
- **触发区**：只读展示区，显示已选标签为 chips（或占位「选择标签」），点击打开 `el-dialog`。
- **弹窗内容**：
  - 顶部 `el-input`（filterable）：输入文字即时过滤标签；输入不存在名称时出现「创建 "xxx"」提示，按回车调 `createTag(name)` + `appStore.fetchTags()` 刷新缓存，并自动选中新标签（allow-create 交互）。
  - 字母索引条 `AlphabetNav`：点击字母滚动/过滤到对应分组。
  - 标签网格：按 `groupTagsByInitial` 分组展示，点击标签 toggle 选中（高亮）。
  - 底部：已选标签预览 + 「确定 / 取消」按钮；确定时 emit 更新。
- 复用 `src/api/admin.js` 的 `createTag` 与 `src/stores/app.js` 的 `tags` / `fetchTags`。

### 6. 改造 `src/components/anime/AnimeForm.vue` — 替换标签表单项

- 第 126-130 行的 `el-select` 替换为 `<TagSelector v-model="form.tagIds" />`。
- 引入并注册 `TagSelector` 组件。
- 表单校验 `rules.tagIds`（第 327 行）保持不变，`form.tagIds` 结构不变（仍为 `number[]`），因此提交逻辑无需改动。
- 删除不再使用的 `const tags = computed(() => appStore.tags)`（第 235 行）及相关引用，避免冗余（遵循「不用的代码不留」）。
