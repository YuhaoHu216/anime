# 页面分享功能 实现计划

## Context（背景）

当前系统所有用户数据接口（首页统计、收藏夹、追番记录）都由 `JwtInterceptor` 拦截，未登录一律返回 401，用户数据只能本人登录后查看。

目标是新增「页面分享」能力：每个用户有一个公开主页，**未登录用户**也能通过分享链接（`/share/{account}`）访问该用户的**个人信息、收藏夹、追番记录**；且这三类信息各自可配置「公开 / 隐藏」。

已确认的决策：
- 隐私配置粒度：**分模块独立开关**（个人信息 / 收藏夹 / 追番记录 各自独立）。
- 实现范围：**后端 + 前端**。
- 分享标识：**账号 account**（全局唯一，`uk_account`），链接形如 `/share/{account}`。

---

## 一、后端改动

### 1. 数据模型：user 表新增 3 个隐私开关字段

`profile_public`（个人信息）、`collection_public`（收藏夹）、`watch_public`（追番记录），均 `TINYINT(1) DEFAULT 0`。

同步 ALTER（已部署库执行，注释见 `src/main/resources/sql/anime.sql`）：

```sql
ALTER TABLE user
  ADD COLUMN profile_public TINYINT(1) DEFAULT 0 COMMENT '个人信息是否公开',
  ADD COLUMN collection_public TINYINT(1) DEFAULT 0 COMMENT '收藏夹是否公开',
  ADD COLUMN watch_public TINYINT(1) DEFAULT 0 COMMENT '追番记录是否公开';
```

### 2. 隐私配置接口（登录后使用）

- `GET /user/privacy`、`PUT /user/privacy`（body 为 `PrivacyUpdateDTO`）。

### 3. 分享公开接口（无需登录，`/share/**` 白名单放行）

- `GET /share/{account}?startDate=&endDate=` → `ShareProfileDTO`（个人信息 + 公开收藏夹 + 追番统计/最近记录）。
- `GET /share/collections/{collectionId}/items?page=&pageSize=` → 公开收藏夹条目。

## 二、前端改动

- 新增 `src/api/share.js`；`src/api/user.js` 增加 `getPrivacy/updatePrivacy`。
- 路由新增公开页：`/share/:account`（分享主页）、`/share/collections/:id`（公开收藏夹）。
- 新增 `src/views/ShareProfile.vue`、`src/views/ShareCollection.vue`。
- `src/views/Profile.vue` 增加「隐私设置」与「分享我的主页」卡片。

## 四、验证

后端 `mvn -q compile`、前端 `npm run build`，均通过。

---

## 五、备注

- 三个隐私开关默认均 `0`（隐藏），新老用户默认不泄露任何信息。
- `ShareUser` 不返回 email/phone/password。
- 上线需在数据库执行上面的 ALTER 语句，否则 `select * from user` 会报未知列。
